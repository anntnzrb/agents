# Pi CLIProxyAPI extension

The extension resolves models from the configured CLIProxyAPI rich `/models?client_version` catalog at startup. It falls back to the shared normalized catalog only when the gateway is unavailable.

`piThinkingLevelMap()` projects ordered reasoning efforts onto Pi's closed thinking-level set. Unsupported Pi levels map to `null`, and `max` maps to the last advertised effort. This keeps an unknown future effort reachable through `max`.
