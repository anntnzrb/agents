# Pi harness source

## Native MCP

Sync generates `~/.pi/agent/mcp.json` from `../../tools/mcporter/mcporter.jsonc` and merges exact skill exclusions into the generated settings from `agent/settings.json`. The registry's `piSkill` metadata identifies replaced skills. Those skills remain installed but Pi does not load them. Other harnesses still use them through mcporter.

Native servers use Pi's default codemode exposure and the registry descriptions. Edit the registry, not the generated files. Sync replaces native server configuration and exclusions on every reconciliation, including local changes made through `/mcp`.

Pi does not recognize shell-style environment defaults. Sync keeps populated variables as `${VAR}` references without writing their values, uses declared defaults for empty or unset variables, and omits empty optional headers. This selection uses the repository `.env` defaults overridden by the sync process environment. Rerun sync after changing those variables. Pi fails on an unresolved `${VAR}` header and sends an explicitly empty header rather than omitting it.

Pi passes stdio arguments literally. For arguments containing environment references, sync emits a quoted `sh -c` command that expands references at launch and then uses `exec`. Credential values remain out of the generated file. This adapter supports the repository's macOS and Linux platforms.

After publication, run `pi mcp list` to inspect connections. Missing credentials or unavailable services can fail connections without indicating a configuration parse error.

## Herdr integration

`agent/extensions/herdr-agent-state.ts` is Herdr's Pi integration. `../omp/agent/extensions/herdr-omp-agent-state.ts` is Herdr's OMP integration. Both are generated by `herdr integration install` and committed unedited. They report agent state to Herdr only when Herdr sets `HERDR_ENV`, `HERDR_SOCKET_PATH`, and `HERDR_PANE_ID`. Outside Herdr they do nothing.

They live in the SSOT because sync prunes `extensions/`: a local `herdr integration install` into `~/.pi` or `~/.omp` is deleted on the next sync. They keep Herdr's file names so that `herdr integration status` finds them in the synced homes.

Herdr prints "installed herdr integrations need updating" after an update that ships a newer integration version. Regenerate both files from the repository root with the installed Herdr, then commit:

```sh
HOME=$PWD/harnesses PI_CODING_AGENT_DIR=$PWD/harnesses/pi/agent herdr integration install pi
HOME=$PWD/harnesses PI_CONFIG_DIR=omp herdr integration install omp
herdr integration status
git add harnesses/pi/agent/extensions/herdr-agent-state.ts harnesses/omp/agent/extensions/herdr-omp-agent-state.ts
git commit -m "pi, omp: update herdr integrations"
```

The overridden `HOME` and agent directories point `install` at the SSOT. The OMP command needs its own `HOME` because Herdr refuses to install OMP when it resolves to Pi's extension directory. `status` reads the synced homes, so it reports `current` only after sync publishes the new files.

Other Herdr integrations are not tracked. The Claude Code, Codex, and Devin installs write absolute hook paths into `settings.json`, `hooks.json`, and `config.json`. Those are sync-managed files in a public repository, and those integrations report only session identity; state still comes from Herdr's screen detection. The OpenCode install also edits `cli.json` and `tui.jsonc`.

## Validate active extensions

Run the test suite from the repository root:

```bash
uv run --script .github/scripts/ci.py harness pi
```

The CI runner copies active extension sources to a temporary directory, installs the committed Bun lockfile with `--frozen-lockfile`, and runs module tests with HTTP transport blocked. Host modules and standalone ripgrep are development dependencies in `agent/extensions/package.json`; the runner exposes packaged ripgrep on `PATH`. CI does not invoke Pi, Codex, or provider APIs. Legacy extensions are excluded. Native apply-patch integration remains a [manual check](agent/extensions/apply-patch/README.md#load-and-validate).
