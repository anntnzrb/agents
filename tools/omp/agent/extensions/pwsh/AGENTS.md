# OMP pwsh extension

## Purpose

Adds an OMP `pwsh` tool for Windows-native PowerShell execution.

## Files

- `index.ts` — extension entrypoint, tool registration, shell resolution, execution, Windows active-tool policy.
- `prompt.md` — model-facing PowerShell guidance.
- `validation-suite.ps1` — PowerShell behavior validation script for Windows and local pwsh installs.

## Policy

- Windows sessions: keep `pwsh` active and remove `bash` from active tools.
- macOS/Linux sessions: register `pwsh` as default-inactive unless explicitly requested.
- Durable source lives here under `~/.config/agents/tools/omp/agent/extensions/pwsh/`; runtime copies under `~/.omp/agent/extensions/pwsh/` are generated by the SSOT sync app.

## Validation

- Sync from `~/.config/agents`: `bun ./sync/src/cli.ts`.
- Load extension explicitly with OMP before trusting runtime discovery.
- If PowerShell is installed, run a child OMP scenario using `--tools pwsh` and validate Unicode output.
- On Windows, run `validation-suite.ps1` through the `pwsh` tool and confirm active tools include `pwsh` and exclude `bash`.

## Stop rules

- Do not edit generated runtime copies directly.
- Do not replace OMP core bash behavior with PowerShell behavior.
- Do not use bash syntax in model-facing guidance for this tool.
