# CLI contract

Run with `uv run --script <skill-dir>/scripts/cli.py [--json] COMMAND` (or from this skill directory, `uv run --script scripts/cli.py COMMAND`).
Commands: `fresh`, `build [--level N]`, `weaknesses [query]`, `bosses [query] [--spoilers]`, `route --chapter N [--dlc] [--spoilers]`, `trophies [query] [--dlc] [--spoilers]`, `checklist --chapter N [--dlc] [--spoilers]`, `farm [stage]`, `community [query] [--spoilers]`, `compare --candidate 'NAME,PHYSICAL,ELEMENTAL,CRIT_PERCENT,WEIGHT'` (repeatable), `sources [list|status|explain]`, and `audit`.
`community` reads `resources/community.json` and returns versioned, sourced records for weapons, amulets, and boss walls. It reports verified facts separately from sentiment, dissent, recommendation, context, and confidence; preferences are not mechanics. Without `--spoilers`, spoiler/DLC records are filtered; `--json` changes formatting only.
`compare` accepts one or more candidates. All stats are nonnegative, crit is 0–100, weight is nonnegative; `--motion` is nonnegative, `--critical-multiplier` is at least 1, and retained physical/elemental factors are 0–1. Invalid input returns status 2. It reports displayed_ar = physical + elemental and adjusted_hit = (physical × physical_retained + elemental × elemental_retained) × motion. If a critical multiplier is supplied, expected_hit additionally multiplies by `1 + crit_percent/100 × (critical_multiplier − 1)`; ranking uses expected_hit when available, otherwise adjusted_hit.
The comparator is deterministic displayed-AR arithmetic only: enemy defense, hidden scaling/saturation, animation DPS, status buildup, and Fable effects are excluded. It does not claim exact hidden AR, scaling, or DPS.
`fresh` displays version, difficulty, and the complete build object. `build` displays the same build object, adding `level` when `--level N` is supplied; its weapon fields describe the Technique lane: Path of the Bastard or Wintry Rapier start, Booster Glaive handle in Chapter 3, Bone-Cutting Sawblade acquisition in Chapter 5's Malum District, then Sawblade + Booster assembly.
Output is deterministic UTF-8 text; `--json` emits compact sorted-key JSON and never bypasses spoiler filtering. Without `--spoilers`, `bosses` returns aggregate count/type guidance and a named query returns only that base-game boss's name and generic guidance; it never discloses future names, areas, or plans. `--spoilers` returns full rows. Missing or malformed resources and invalid arguments print an error to stderr and return status 2. `audit` checks required top-level schemas, normalized source-registry fields (`url`, `title`, `kind`, `checked`, `version_scope`, `confidence`, `license_or_terms`, `notes`), deterministic collection counts, and the required 43 base/11 Overture trophy counts.
