# Autoincludes

Clan auto-registers every folder under `machines/{machineName}` as a machine and auto-imports these files for every machine:

- `machines/{machineName}/configuration.nix` — main machine configuration.
- `machines/{machineName}/hardware-configuration.nix` — hardware-specific configuration generated by NixOS.
- `machines/{machineName}/facter.json` — automatically generated system facts; details: [nixos-facter](https://clan.lol/blog/nixos-facter/).
- `machines/{machineName}/disko.nix` — disk-layout configuration; details: [disko quickstart](https://github.com/nix-community/disko/blob/master/docs/quickstart.md).

Other auto-included files:

- `inventory.json` — managed by Clan's API; merges with `clan.inventory` to extend the inventory.
- `.clan-flake` — sentinel for locating a Clan repository root. If absent, Clan falls back to `.git`, `.hg`, `.svn`, or `flake.nix`.
