## Decision record template by Michael Nygard

Template from [Documenting architecture decisions - Michael Nygard](https://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
[adr-tools](https://github.com/npryce/adr-tools) can manage ADR files.

Write these sections in each ADR file:

# Title

## Status

Status, e.g. proposed, accepted, rejected, deprecated, superseded, etc.

## Context

Issue seen that motivates this decision or change.

## Decision

Change proposed and/or being made.

## Consequences

What becomes easier or more difficult because of this change?
